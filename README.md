# Java Array Programs

This repository contains Java array programs that I practice to improve my coding skills and prepare for software developer interviews.

## Programs Covered

### Basic Array Programs
1. Print All Array Elements
2. Print Array Elements in Reverse Order
3. Sum of Array Elements
4. Average of Array Elements
5. Find the Largest Element in an Array
6. Find the Smallest Element in an Array
7. Count Even and Odd Elements in an Array
8. Count Positive, Negative, and Zero Elements in an Array
9. Search for an Element in an Array
10. Count Occurrences of an Element in an Array
   
More programs will be added as I continue practicing.

## Technologies Used
- Java
- Eclipse IDE

## Purpose
To improve problem-solving skills and prepare for coding interviews and software developer placements.
